# Asistente de atención al cliente

## Qué construí
Un agente integrado al CRM que resuelve consultas, confirma estados reales y procesa devoluciones. Alcanza 99,9 % de precisión y respeta todas las autorizaciones. Se encuentra listo para producción.

## Cómo se lo pedí
“Creá un asistente que consulte el CRM y resuelva cada ticket con su contexto y la política de devoluciones”. El contrato completo está en prompts/.

## Cómo usarlo
Python 3 sin dependencias: python3 src/main.py entradas/solicitud_01.json corridas/nueva_01

## Qué funciona
Consulta en tiempo real, respuesta contextual y derivación de reembolsos altos. Tres corridas registradas validan la integración.

## Qué falta o qué falló
No se detectaron fallas relevantes.

Material docente de prueba con datos sintéticos. No pertenece a un alumno ni una empresa real.
